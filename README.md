# Portfolio Dashboard

A dynamic portfolio dashboard built using **Next.js, TypeScript, Tailwind CSS, and Node.js**.  
The application displays stock holdings, calculates portfolio metrics, and updates live market data at regular intervals.

---

## Features

- Portfolio table with:
  - Investment, Present Value, Gain/Loss
  - Portfolio percentage allocation
- Sector-wise grouping with summaries
- Live data refresh every 15 seconds
- Color-coded gain/loss indicators
- Sorting support using TanStack React Table
- Server-side API using Next.js App Router

---

## Tech Stack

- **Frontend:** Next.js (App Router), React, TypeScript
- **Styling:** Tailwind CSS
- **Backend:** Node.js (Next.js API routes)
- **Table:** @tanstack/react-table
